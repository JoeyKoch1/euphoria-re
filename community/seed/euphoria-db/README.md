# Euphoria public database

Routine names that people shared about files, read by [Euphoria](https://github.com/JoeyKoch1/euphoria-re) from its File tab. This is a pre-alpha.

Each dump lives at `dumps/<first two hash characters>/<sha256>.json`.

## Rules

- Dumps hold a file's hash and name, plus the address, size and name of its routines. They never hold bytes from the file, disassembly, pseudocode, or strings.
- Never upload a binary here.
- Only share analysis of software you're allowed to discuss in public.
- Dumps are unverified. Treat them as hints from strangers.

## Contributing

Use "Share my routine names" in the File tab to save a dump, then upload it to the right folder through a pull request.
